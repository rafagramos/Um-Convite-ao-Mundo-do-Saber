📒 Descrição 

Um-Convite-ao-Mundo-do-Saber

Elaboração de e-book do Livro Despertar para a Filsofia: Um Convite ao Mundo do Saber

🤖  Tecnologias e 🧐 Processo de Criação

No Chat GPT usei os seguintes prompts

Prompt: Crie opções de títulos para um livro sobre introdução a filosofia .

Prompt: Crie opções de títulos memoráveis para um livro sobre introdução a filosofia .

Foram apresentados algumas opções e solicitei que gerassem novos títulos.

Após a escolha dos título, com uma combinação de títulos apresentados, solicitei:

Prompt: Crie capítulos para o Livro com o título DESPERTAR PARA FILOSOFIA: Um convite ao Mundo do Saber

Foram gerados 10 títulos de capítulos 

Com cada um deles pedi para gerar

Prompt Crie o capitulo (número do capítulo, (Título do capítulo), com a descrição(descrição gerada) para o livro DESPERTAR PARA FILOSOFIA Um convite ao Mundo do Saber

E repeti o processo para cada um dos capítulos.

Geração da CAPA

Apesar da proposta informar para usar o midjourney, não gostei do funcionamento e achei a quantidade de pedidos muito restritiva. Então usei o LeonardoAI para geração da imagem para capa

Prompt: gere capa para o livro com o título "DESPERTAR PARA FILOSOFIA Um convite ao Mundo do Saber"

Prompt: gere capa para o livro com o título "DESPERTAR PARA FILOSOFIA Um convite ao Mundo do Saber" com imagem de livros que remeta a filosofia.

Prompt: gere capa para o livro com o título "DESPERTAR PARA FILOSOFIA Um convite ao Mundo do Saber" com imagem de livros com feixes de luz.

Prompts: gere imagem que tenha livro com feixes de luz

No power point
Após selecionada a imagem baixei para o computador e colei a imagem escolhida EM arquivo .

Editei a imagem para completar a imagem porque o tamanho não estava ideal.

Criei a página inicial dos capítulos, e depois criei as páginas para o texto dos capítulos.

Salvei o arquivo em PDF.
